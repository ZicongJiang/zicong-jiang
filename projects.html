Physics-informed machine learning for optical fiber channel modeling

Course: EENX16 (Bachelor Thesis)
Available
Fiber Communication Physics-Informed ML Fiber Modeling Python/PyTorch
Supervisors Zicong Jiang, Assist. Prof. Christian Häger
Target Group TKAUT, TKMAS, TKELT, TKDAT, TKTFY, TKMED
Group Size 3–6 Students
Language English (Report)

Abstract

Optical fiber communication systems form the backbone of modern digital infrastructure. However, traditional modeling methods like the split-step Fourier method (SSFM) are computationally expensive. This project bridges optical fiber communication and machine learning by exploring how recent Physics-Informed Machine Learning (PIML) methods (such as PINNs and Neural Operators) can be utilized for fast and physically consistent fiber channel modeling.

Project Goals

  • Baseline Modeling: Implement a reference optical fiber propagation model using SSFM.
  • PIML Development: Develop and train physics-informed neural models (PINNs, PINO, or FiberKAN) to learn fiber channel dynamics.
  • Evaluation: Compare the accuracy and inference speed of AI-based approaches against the SSFM benchmark.

Prerequisites

Interest in optical fiber communications; Basic knowledge of machine learning and Python.
